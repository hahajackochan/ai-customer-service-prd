# AI客服 PRD（消费者业务中台）

**在线预览：** https://hahajackochan.github.io/ai-customer-service-prd/

- **当前版本：** v1.22（2026-09-11）
- **产品经理：** 陈嘉豪
- **系统归属：** 消费者业务中台 / 租户端

## 内容

| 文件 | 说明 |
|---|---|
| `index.html` | PRD 正文（项目信息、需求背景、需求功能清单、详细方案、内嵌原型） |
| `原型/*.html` | 独立自包含 HTML 原型，其中 8 个经相对路径 iframe 内嵌进 PRD；`会话消息详情_v1.0.html` 由列表「聊天」入口进入 |

## 模块

智能体管理、工作流管理、供应商管理、艾客坐席管理、AI托管账号、会话接待插件H5、客户会话管理、会话消息管理、AI回复响应管理。

## 说明

- 原型数据均为模拟示例，不含真实 AI 执行或生产接口。
- 除智能体管理外，其余 7 个后台列表在「筛选」按钮右侧提供「导出」入口按钮（原型未实现下载交互）。
- 全部文件零外部 CDN，可直接 `file://` 离线打开。
