# AI客服 PRD（消费者业务中台）

**在线预览：** https://hahajackochan.github.io/ai-customer-service-prd/

- **当前版本：** v1.112（2026-10-13）
- **产品经理：** 陈嘉豪
- **系统归属：** 消费者业务中台 / 租户端

## 内容

| 文件 | 说明 |
|---|---|
| `index.html` | PRD 正文（项目信息、需求背景、需求功能清单、详细方案、附录、内嵌原型） |
| `原型/*.html` | 独立自包含 HTML 原型，其中 12 个经相对路径 iframe 内嵌进 PRD；`会话消息详情_v1.0.html` 由列表「聊天」入口进入 |

## 模块

智能体管理、工作流管理、意图管理（智能体管理·意图配置）、供应商管理、AI托管账号、会话接待插件H5、客户会话管理、会话消息管理、AI响应明细、AI客服配置（租户管理·基础配置）、角色管理（租户管理·数据权限）。

## 说明

- 原型数据均为模拟示例，不含真实 AI 执行或生产接口。
- 除智能体管理外，其余 7 个后台列表在「筛选」按钮右侧提供「导出」入口按钮（原型未实现下载交互）。
- AI托管账号的列表在筛选区左侧提供「同步」入口按钮（原型未实现真实同步）。
- AI托管账号的「编辑」弹窗按单聊 / 群聊分组配置，开启后必须各自选择一个「意图识别」工作流（两者可不同）；客户会话管理的「聊天内容」默认定位最新记录并只加载最新 10 条，上滑到顶部时每次加载更早的 10 条。
- 工作流管理新增 / 编辑弹窗在工作流ID下方依次维护Aily应用ID、Aily技能ID，均为必填；编辑时支持回显与修改，智能体与工作流类型仍只读；工作流管理不再配置槽位参数与追问话术。
- AI客服配置位于租户管理「基础配置」，弹窗内设置执行AI接管等待时长（正整数·秒）并按工作日 / 非工作日独立设置自动启用单聊AI托管，开启时必填开启时间；下方新增「飞书多维表格配置」，点击【新增】选择数据字典用途（示例：同步意图库、拉取AI追溯日志）后必填app_token、table_id，同一租户同用途不可重复维护，支持保存回显与取消不落库（原型配置存于浏览器本地）。
- 角色管理位于租户管理「角色管理」，列表操作列提供【数据权限】入口；弹窗左侧为「数据类型」列表（当前仅「AI托管账号」一个类型，结构支持后续扩展），右侧保留穿梭框。AI托管账号按「供应商 → 账号」树形分组，点击艾客、探马等供应商展开 / 折叠旗下账号并选择，已选账号附供应商名称；左侧仅显示各供应商账号数，支持账号名称 / ID搜索及各供应商独立全选 / 取消全选；右侧仅显示已选数量，保留清空及保存回显，权限仍按账号实体ID保存（原型内置艾客、探马各18个账号，权限存于浏览器本地）。
- 会话消息管理的「转人工归因」为固定 6 个枚举：用户主动要求人工、FAQ知识缺失、商品知识缺失、智能体工作流异常、业务API异常、业务规则要求人工（枚举值与判定逻辑见 PRD 4.7）；每条消息记录右侧均提供【AI决策追溯】入口，不存在整体为空的情况；每条有效消息保留追溯ID、会话ID与触发消息，未执行或未产出的环节单独说明，不虚构AI识别、知识匹配或回复，也不将人工回复标为AI输出。
- AI决策追溯的意图识别仅展示二级意图分类名称、二级意图分类标识、识别槽位参数、工作流名称、Aily工作流技能ID；知识匹配按关联工作流类型展示知识库的检索知识片段 / 知识匹配度 / 知识文档名称，或业务API的接口请求地址 / 请求参数 / 返回参数。知识匹配默认显示3行，超出时在标题右侧展开 / 收起，示例数据不调用真实接口。
- AI响应详情删除匹配决策、回复生成、回复后处理三个环节，保留系统接收、意图识别、知识检索和回复发送信息；相关原型入口保持一致。
- 意图管理位于「智能体管理」菜单，列表记录业务类型、一级 / 二级意图分类、二级意图分类标识、工作流绑定及创建 / 更新审计字段（意图扩写、请求接口、槽位参数与追问话术仅在新增 / 编辑弹窗维护，不在列表展示；请求接口配置项位于槽位参数上方）；业务类型选项来自中台数据字典，一级 / 二级意图分类自行创建维护，意图扩写（经典提问）在新增 / 编辑弹窗内直接维护（必填，0–10条，为空保存拦截），工作流选择自「工作流管理」并自动带出工作流ID；请求接口为可空的单选下拉，选项按「接口名称（请求地址）」展示，随意图保存所选接口标识；槽位参数为可空的单选下拉，选择槽位参数后追问话术必填，未选择时追问话术可空，原型仅提供模拟选项且不发起真实请求。新增意图需填写「二级意图分类标识」（仅一级分类提供联想；名称命中同一一级下已有分类时自动带出标识，同一一级下二级名称与标识均需唯一，重复保存时拦截提示，创建后业务类型、分类与标识不可修改）；列表左侧提供【同步】按钮，点击后将意图数据同步至飞书知识空间，完成后提示「X条记录同步成功」，筛选条件含二级意图分类标识与工作流ID，列表记录按创建时间倒序展示、业务类型列纯文本展示；新增/编辑弹窗不展示工作流ID（工作流下拉已同时含名称与ID，原型为模拟提示）。
