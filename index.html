AI客服 PRD

本期建设三方账号管理、会话接待插件H5、AI会话管理、智能体管理及租户基础配置（AI客服配置），支持单聊 / 群聊AI接管独立配置、按工作日 / 非工作日定时自动启用单聊AI接管、会话 / 消息查询、转人工归因追溯、AI回复耗时分析，以及智能体应用凭证与工作流配置；不实现真实AI执行。原型均为模拟数据。

前端规则逻辑

  • 执行AI接管等待时长：只能填写正整数，不填写的情况下默认0；
  • 自动启用单聊AI托管：支持按工作日和非工作日自动启用AI账号和所有单聊会话；当勾选自动启用后，必须选择启用的时间；

  • 自动启用单聊AI托管逻辑：系统每5分钟执行一次定时任务，检查工作日和非工作日是否有勾选，无勾选则结束定时任务，当有任一勾选启用，执行以下逻辑：
  • （1）调用外部接口检查今天是否为工作日，判断是否满足工作日/非工作 和 开启时间的要求，若满足的情况下，将所有托管账号的AI接管状态改为启用 并且 将账号下所有单聊会话的AI接管状态改为启用。
  • （2）查询工作日，可考虑采用此外部接口 或 技术另寻其他接口，下方接口支持传入日期，接口会返回类型 工作日/节假日/周末。

4.10 角色管理（数据权限）

消费者业务中台 / 租户管理（角色管理）
角色管理：租户在「租户管理 / 角色管理」按数据类型为每个角色设置可查看的数据范围；系统管理员进入中台后，AI托管账号、客户会话管理、会话消息管理、AI响应明细等界面按当前登录人所属角色的授权范围展示数据。当前数据类型为「AI托管账号」，弹窗结构支持后续扩展更多数据类型。

前端规则逻辑

  • 数据类型：弹窗顶部为数据类型页签，当前仅「AI托管账号」一个类型且默认选中，后续新增类型时自动增加页签，切换页签即切换下方该类型的数据勾选区，各类型已选数据互相独立。
  • 数据勾选（AI托管账号类型）：左侧显示当前租户的所有AI托管账号（账号名称 + 账号ID），点击记录自动加入右侧「已选账号」列表，点击右侧记录移回左侧；左侧提供搜索框，支持按账号名称 / 账号ID模糊匹配。

交互逻辑

  • 打开弹窗：按角色读取已保存的授权数据，按数据类型分别回填到各自的已选列表；切换页签时清空左侧搜索条件并展示该类型的数据。
  • 批量操作：左侧提供「全选 / 取消全选」，作用于当前类型下搜索命中的记录；右侧提供「清空已选」，清空当前类型已选。

后端处理逻辑

  • 登录人进入AI托管账号、客户会话管理、会话消息管理、AI响应明细等界面时，按当前登录人所属角色的授权账号集合过滤数据；未授权账号的数据不返回、不可见。
