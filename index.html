AI客服 PRD

本期建设三方账号管理、会话接待插件H5、AI会话管理、智能体管理（含意图管理）及租户基础配置（AI客服配置），支持单聊 / 群聊AI接管独立配置、按工作日 / 非工作日定时自动启用单聊AI接管、会话 / 消息查询、转人工归因追溯、AI回复耗时分析，以及智能体应用凭证、工作流与意图配置；不实现真实AI执行。原型均为模拟数据。

二、需求背景

当前企微私域运营覆盖单聊、客户群聊两大私域触点，主要用于承接定制获客、成品销售、会员服务三大业务。现阶段进线咨询直接流转人工客服，AI减负、转化赋能价值未释放，制约私域人力效率与客户承接转化能力。

4.6 客户会话管理

消费者业务中台 / AI会话管理
客户会话管理：管理每个客户和成员的会话，每个客户和成员只要产生对话，就会有一条会话记录，可进入详情查看完整对话过程、AI决策追溯和AI耗时明细；

前端规则逻辑

  • AI接管状态：账号已开启单聊AI接管时才可编辑，不满足前提时启用 / 禁用两项均置灰不可选，弹窗内提示「托管账号AI接管状态已关闭，请先启用。」并提供「去配置」，点击跳转AI托管账号、按账号ID自动搜索出该账号记录。
  • 涉及AI回复：只读；该会话有实际AI发送记录时显示「是」，否则显示「否」。
  • 会话明细的成员回复消息，若为AI回复，则颜色需要高亮，并且需要显示AI回复、AI决策追溯、耗时详情按钮，点击AI决策追溯和耗时详情按钮，右侧以抽屉形式展示对应内容；
  • 列表数据范围：仅展示当前登录人所属角色已授权的AI托管账号下的数据，未授权的账号数据不展示（权限在「租户管理 / 角色管理」的【数据权限】中维护，见4.10）。

交互逻辑

  • 「聊天内容」详情进入时默认定位到最新记录（滚动到底部），首屏只渲染最新10条消息。
  • 向上滚动到列表顶部时自动加载更早的10条（每次请求前10条），加载过程在列表顶部提示「正在加载更早的记录…」；加载完成后保持当前阅读位置不跳动。

4.7 会话消息管理

消费者业务中台 / AI会话管理
会话消息管理：当单聊开启AI接管后，会记录客户发送的消息，并且会自动关联AI决策追溯ID。

关联关系示意图：列表记录以客户消息ID为主要ID，1条客户消息关联1条AI决策追溯ID，1条AI决策追溯ID可能输出多条AI回复消息。

前端规则逻辑

  • 列表-成员回复内容：当成员未回复或转人工的情况下，显示-，若为AI回复的则显示AI回复内容，需注意AI存在回复多条消息的情况，多条消息的情况下，每条消息需要新增一个序号 并且 换行展示。
  • 列表-转人工：当AI转人工后，此字段显示是，反之显示否；
  • 列表-转人工归因：AI转人工时展示该次转人工的归因枚举（用户主动要求人工、FAQ知识缺失、商品知识缺失、智能体工作流异常、业务API异常、业务规则要求人工），非转人工的记录显示-；筛选条件「转人工归因」可选择上述任一枚举，选定后仅展示该归因的记录。
  • 列表-AI决策追溯按钮：当客户消息是通过AI回复或转人工的情况下，需要显示AI决策追溯按钮；
  • 列表数据范围：仅展示当前登录人所属角色已授权的AI托管账号下的数据，未授权的账号数据不展示（权限在「租户管理 / 角色管理」的【数据权限】中维护，见4.10）。

交互逻辑

  • 当客户消息有AI回复、或由AI判定转人工时，显示「AI决策追溯」按钮，点击后在右侧展示该客户消息所属的追溯过程；被并入后续追溯的客户消息，按钮指向所属的那条追溯。

后端处理逻辑

转人工归因枚举值及映射逻辑处理：

  • 用户主动要求人工（对应逻辑：用户输入关键词“人工、转人工”）
  • FAQ知识缺失（对应逻辑：查询FAQ知识库没有对应的知识片段）
  • 商品知识缺失（对应逻辑：查询商品知识库没有对应的知识片段）
  • 智能体工作流异常（对应逻辑：进入智能体工作流异常了，这里是智能体平台返回异常，如飞书aily、扣子等）
  • 业务API异常（对应逻辑：查询业务API时返回400、500等报错，这里指业务系统返回的异常）
  • 业务规则要求人工（对应逻辑：命中意图库的要求转人工的意图，含高风险问题情绪投诉等）
  • 待确认：同一条客户消息同时满足多个归因条件时的取值口径（例如用户主动要求人工的同时，FAQ知识库也没有对应知识片段），需确认按哪个归因记录、或是否允许一条记录挂多个归因。

4.9 AI客服配置

消费者业务中台 / 租户管理（基础配置）
AI客服配置：租户在「租户管理 / 基础配置」维护的AI客服入口配置，包含执行AI接管等待时长与自动启用单聊AI托管的定时设置；点击卡片【配置】按钮，以弹窗形式设置。

前端规则逻辑

  • 执行AI接管等待时长：只能填写正整数，不填写的情况下默认0；
  • 自动启用单聊AI托管：支持按工作日和非工作日自动启用AI账号和所有单聊会话；当勾选自动启用后，必须选择启用的时间；

  • 等待时长：当AI托管账号的AI接管状态为启用 且 会话的AI接管状态为启用时，客户发送消息达到等待时长后，AI将自动获取客户最近发送的消息，执行AI客户流程。
  • 自动启用单聊AI托管逻辑：系统每5分钟执行一次定时任务，检查工作日和非工作日是否有勾选，无勾选则结束定时任务，当有任一勾选启用，执行以下逻辑：
  • （1）调用外部接口检查今天是否为工作日，判断是否满足工作日/非工作 和 开启时间的要求，若满足的情况下，将所有托管账号的AI接管状态改为启用 并且 将账号下所有单聊会话的AI接管状态改为启用。
  • （2）查询工作日，可考虑采用此外部接口 或 技术另寻其他接口，下方接口支持传入日期，接口会返回类型 工作日/节假日/周末。
  • 万维易源-节假日查询接口  https://www.showapi.com/apiGateway/view/894/6

  • 数据勾选（AI托管账号类型）：左侧显示当前租户的所有AI托管账号（账号名称 + 账号ID），点击记录自动加入右侧「已选账号」列表，点击右侧记录移回左侧；左侧提供搜索框，支持按账号名称 / 账号ID模糊匹配。

交互逻辑

  • 打开弹窗：按角色读取已保存的授权数据，按数据类型分别回填到各自的已选列表；切换类型时清空搜索条件并展示该类型的数据。
  • 批量操作：左侧提供「全选 / 取消全选」，作用于当前类型下搜索命中的记录；右侧提供「清空已选」，清空当前类型已选。

后端处理逻辑

  • 登录人进入AI托管账号、客户会话管理、会话消息管理、AI响应明细等界面时，按当前登录人所属角色的授权账号集合过滤数据；未授权账号的数据不返回、不可见。
  • 权限按「角色 + 数据类型 + 具体数据实体ID（如AI托管账号ID）」维度存储。
原型 · 角色管理
模拟租户管理「角色管理」列表与新增的【数据权限】入口；内嵌原型默认打开数据权限弹窗，关闭后可查看列表「操作」列新增的按钮。弹窗左侧为「数据类型」列表（当前仅「AI托管账号」一个类型，结构支持后续扩展），右侧为左右穿梭形式：左侧可搜索账号并点击加入右侧已选列表，右侧点击可移出（原型内置 36 个账号演示，权限存于浏览器本地）。

4.11 意图管理

消费者业务中台 / 智能体管理

前端规则逻辑

  • 新增 / 编辑弹窗包含业务类型、一级意图分类、二级意图分类、二级意图分类标识、工作流、意图扩写、追问话术，均为必填：
    1. 业务类型为下拉选择，选项值取数据字典；
    2. 一级 / 二级意图分类为输入框，支持自行创建维护，仅一级意图分类输入时联想已有分类（会基于已输入的内容，模糊匹配现有的一级意图分类）
    3. 二级意图分类标识为输入框必填（如 product_price），输入的二级意图分类名称命中同一一级分类下已有分类时，自动带入对应的二级意图分类标识且不可编辑；
    4. 工作流名称为下拉选择，选项为「工作流管理」已维护的工作流（展示「工作流名称（工作流ID）」）；
    5. 意图扩写：必填，最多填写10条意图扩写；
    6. 保存时校验同一一级意图分类下二级意图分类名称与二级意图分类标识唯一：名称重复提示「同一一级意图分类下二级意图分类名称已存在，请修改」，标识重复提示「同一一级意图分类下二级意图分类标识已存在，请修改后重试」；
  • 编辑意图时业务类型、一级意图分类、二级意图分类、二级意图分类标识只读不可修改，仅工作流、意图扩写、追问可修改。

交互逻辑

  • 列表「意图扩写（经典提问）」列默认仅展示前 2 条，超出时显示「查看全部」，点击就地展开全部并显示「收起」，点击「收起」恢复默认展示。

后端处理逻辑

  • 点击同步按钮，会将现有意图管理的内容，同步至飞书的知识空间。
原型 · 意图管理
模拟中台「智能体管理 / 意图管理」列表与新增 / 编辑弹窗（意图扩写在弹窗内维护）；左侧「同步」按钮为同步至飞书知识空间的入口模拟。示例数据中售后服务咨询的二级分类、会员服务的分类与部分工作流为演示补全，以需求方确认为准。
