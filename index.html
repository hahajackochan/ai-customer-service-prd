AI客服 PRD

本期建设三方账号管理、会话接待插件H5、AI会话管理及智能体管理，支持单聊 / 群聊AI接管独立配置、会话 / 消息查询、转人工归因追溯、AI回复耗时分析，以及智能体应用凭证与工作流配置；不实现真实AI执行。原型均为模拟数据。

4.5 AI托管账号

消费者业务中台 / 三方账号管理

前端规则逻辑

  • 筛选条件：账号名称、账号ID、单聊AI接管、群聊AI接管、是否在线；列表展示供应商、账号ID、账号名称、头像、手机号、开启AI接管联系人数、单聊AI接管、群聊AI接管、更新时间及操作。
  • 单聊AI接管、群聊AI接管在列表只读展示「是 / 否」，不展示开关，不提供列表内切换。
  • 企业名称、联系人、设备名称、设备保管者、是否在线、所属组不在列表展示；点击「详情」展示该账号全部字段，供应商为「艾客」时额外展示上述6个供应商扩展字段，其他供应商不展示该区域。
  • 意图识别工作流取自工作流管理中类型为「意图识别」的工作流（如「会员服务意图识别」「售后意图识别」），下拉选项同时展示工作流名称与工作流ID（格式：工作流名称（工作流ID）），单聊与群聊可分别绑定不同工作流。
  • 「详情」在账号基础信息与供应商扩展字段之外展示「AI接管配置」：单聊 / 群聊AI接管状态及各自绑定的意图识别工作流，未开启的类型显示「—」。

交互逻辑

  • 点击「编辑」打开「编辑AI接管配置」弹窗，单聊AI接管与群聊AI接管各自独立分组：勾选开启后组内「意图识别工作流」下拉才可操作，未开启时下拉置灰且不参与保存。
  • 勾选单聊或群聊后必须选择对应工作流：未选择时点击「保存」被拦截，字段标红并提示「必须选择一个意图识别类型的工作流」，弹窗不关闭、数据不写入；选择后即时清除错误提示。
  • 单聊与群聊可分别选择不同的意图识别工作流；取消勾选后该组工作流不再参与保存，重新勾选时回显上次选择。点击「详情」打开详情弹窗，关闭后返回当前筛选结果。
  • 「同步」按钮位于列表筛选区左侧：点击后按钮置为禁用并显示「同步中…」，同步完成恢复为「同步」并刷新列表，同时提示同步结果。

后端处理逻辑

  • 同步与查询：账号基础信息及在线状态由艾客定时拉取，供应商展示拉取归属；点击「同步」时手动重新拉取一次，进行中忽略重复请求；不再维护或校验账号总「是否AI托管」状态。
  • 单聊 / 群聊AI接管配置按账号ID独立存储；详情按供应商类型返回字段，供应商为艾客时返回企业名称、联系人、设备名称、设备保管者、是否在线、所属组。
  • 「开启AI接管联系人数」由中台统计，随会话AI接管配置更新。
  • 保存AI接管配置时按账号ID分别校验单聊 / 群聊：开启的类型必须携带对应类型的工作流ID，且工作流存在、类型为「意图识别」；校验不通过整笔拒绝并返回原因。
  • 单聊 / 群聊的工作流绑定分别存储、互不影响，未开启的类型不保存工作流ID；绑定的工作流被停用或删除时按无效工作流拦截，编辑时回显为空并要求重新选择。
原型 · AI托管账号（单聊 / 群聊AI接管独立配置、账号详情与筛选查询）

  • 进入页面加载记录；查询应用筛选，重置清空条件。非法数值 / 区间在输入处提示并拦截，无命中显示「暂无符合条件的AI回复记录」。
  • 「详情」展示消息标识、七节点完成时间和阶段耗时；关闭按钮返回，点击遮罩不关闭。查询失败可重试，缺失节点不沿用其他回复数据。

  • 按会话边界、客户消息ID、回复消息ID读取实际发送状态与阶段日志；请求含基础筛选、分页、总响应时长阈值或区间，不接收各环节时间筛选条件。服务端校验数值、区间、归属和权限，返回时间、状态及可计算差值。

  • 失败 / 未完成、首尾缺失、时间乱序分别标「未完成 / 数据缺失 / 时间异常」；未执行阶段标「未执行」，缺日志标「未记录」。无效值不补0、不命中数值筛选；人工及无AI回复的转人工 / 异常不计有效样本。
